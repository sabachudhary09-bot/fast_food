# 🍔 FastFood – Fast Food Ordering System

A modern and responsive **Fast Food Ordering System** built with **Python and Django**.  
FastFood allows customers to browse food items, view product details, add items to a shopping cart, select order preferences, and place orders easily through WhatsApp.

The project is designed with a simple, attractive, and user-friendly interface for a smooth online food ordering experience.

---

## ✨ Features

- 🍔 Browse fast food products
- 📋 View menu and food categories
- 🔎 View product details
- 🛒 Add products to cart
- ➕ Increase or decrease cart quantity
- 🗑️ Remove items from cart
- 🍕 Select food size and options
- 🚚 Choose order type:
  - Delivery
  - Takeaway
  - Dining
- 💬 Place orders through WhatsApp
- 🔥 Popular food items section
- 🎁 Offers and special deals section
- 📄 Downloadable menu PDF
- 📍 Location section
- 📱 Responsive design for different screen sizes
- 📞 Contact information and social links
- ⚡ Fast and simple user experience
- 🔐 Django admin panel for managing products and data
